#1 剪映口播重拍自动粗剪：字幕/脚本 → detect-retakes → 保留后一次 → OTIO 字幕往返 → lint/人工实开 · 99

核心判断：capcut-cli v0.22.0 把重复 take 检测、脚本正确文字+Whisper 时间、字幕 OTIO 往返和 draft_materials 注册放进同一条确定性链，最适合先解决真人口播重拍与字幕交接。

解决的问题：同一句多次重录需要人工反复听，自动粗剪容易误删正确版本，跨 NLE 时字幕还可能丢失或不可编辑。

主流方案对比：LLM 自由删句灵活但风险高；静音检测识别不了重复语义。基于字幕 cue 的重拍检测更受约束，适合作为低风险前置粗剪。

今天可以做：拿 3–5 分钟真实口播，跑 detect-retakes，只检查 10 个候选是否正确保留后一次；再做一次 OTIO 字幕往返并 lint，最后在剪映人工打开。

后续机会：若 10 个候选至少 8 个正确且字幕不丢 cue，就固定成“重拍清理 → 字幕交接”步骤；否则只提示不自动删除。

#2 Resolve 多步编辑审计：begin execution → 多次 Agent 写入 → 累计 changes/verification → end execution 后统一验收 · 98

核心判断：execution traces 把一次编辑任务里的多次 _operation 归入同一执行，累计真实变更、耗时和 verification，并保留验证矛盾；任务级验收比逐调用成功更接近真实剪辑结果。

解决的问题：复杂自动剪辑中每次调用都看似正常，但整次任务可能漏执行、重复执行或部分验证冲突，事后难追溯。

主流方案对比：聊天日志不能稳定算出真实改了多少；逐条 _operation 又要人工拼上下文。execution trace 直接把整次任务收束成可审计记录。

今天可以做：在测试项目执行一次删除 5–10 个明确停顿的任务，核对 trace 累计删除数与时间线回读是否一致，并检查 partial/unverified 是否仍然可见。

后续机会：连续 5 次完整任务一致后，把 trace 作为 Blueprint 后每次自动执行的任务级审计记录。

#3 高级感口播包装小样：成品配音+口播稿 → 字级同步 → 3种高价值动效 → 局部重渲 → 回 Resolve/剪映精剪 · 97

解决的问题：动态字卡、数据卡、证据镜头和节奏动效每条都手工搭建，改一个镜头却容易大范围返工。

主流方案对比：剪映模板最快但同质化；AE 最自由但人工成本高。参数化 Remotion 位于中间，可复用、可代码化并能回现有 NLE。

今天可以做：只拿 20–30 秒已剪口播，做一句核心观点字卡、一个数据镜头、一个证据截图转场，比较速度、视觉入片率和修改一次的重渲成本。

后续机会：3 个动效里至少 2 个愿意直接入片，就只沉淀这两类为个人高频组件；否则只当动效代码库。

#4 小红书决策可追溯：趋势/历史反馈 → Evidence Graph → 明确 action intent → 人工确认后执行 · 95

核心判断：Evidence Graph 把 Creator Model、不可变 Decision Record 与 Learning Signal 组合成只读证据投影，action intent 再把“准备做什么”显式化，使判断依据与执行动作分层。

解决的问题：内容 Agent 给出建议后难追溯依据，长期模型更新会让历史理由变模糊，建议和执行混在一起还会增加误操作风险。

主流方案对比：普通聊天式 Agent 最快但不可审计；完整数据仓库又过重。只读证据图 + 显式意图保留了最必要的追溯性。

今天可以做：拿 3 个真实选题，检查每个证据图是否能追到趋势/历史决策/学习信号，再确认 action intent 是否准确表达研究、改稿、发布预览或数据复盘；不自动发布。

后续机会：若 3 个决策都能快速回答“为什么”和“下一步是什么”，就把 Evidence Graph 用于周复盘，并把 action intent 接人工确认门。

#5 跨平台偏好防污染：自动发现任务页 → task-tab 标记 → 丢弃机器滚动/加载事件 → 只学习真人行为 · 94

核心判断：OpenBiliClaw 新修复把 XHS、抖音、B站、YouTube 自动任务 tab 统一标记，并阻止这些页面的 load、scroll、operation 被记录成用户行为；真实浏览器 B站 E2E 还验证搜索任务结束后行为事件为 0。

解决的问题：系统自动找内容时产生的机器浏览动作被误当成真人兴趣，长期污染推荐画像。

主流方案对比：全部浏览器事件都当反馈最简单但污染严重；完全不采行为又丢失隐式偏好。任务 tab 隔离能保留真人学习、排除机器动作。

今天可以做：跑一次跨平台自动发现任务，确认自动任务产生的 load/scroll 行为事件为 0；再手动打开一条真实感兴趣内容，确认真人行为仍能正常留下。

后续机会：连续 20 次自动任务都不产生伪行为后，把 task-tab isolation 设为所有内容研究 Agent 的基础门禁。
